**ESPFormaldehyde** is open-source project for rapid, local measurement of formaldehyde levels in any geographical location in real time, with visual data display on a map, or measuring formaldehyde levels indoors without an internet connection.

# Programs/Libraries that I used

<br>

**[Leaflet]** - *JS Library for interactive map*

**[Python]** - *Language that I used in server(interactive map) code*

**[Arduino IDE]** - *The Best(and easy 2 use) IDE for esp32 in the world*

**[Flask]** - *Library that i use for running server*

**[CodeSandbox]** - *Free VPS with free hosting for interactive map*
